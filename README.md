# Descrição:

Nosso site funciona como uma introdução para aqueles que desejam fazer o processo seletivo do IFRN. Ele conta com dicas de estudo, 
apresenta as responsabilidades acadêmicas e mostra o que de fato é o instituto.

# Uso do Flexbox:
No projeto, o Flexbox foi utilizado no CSS para organizar e alinhar os elementos da página de forma dinâmica e responsiva.

Principais aplicações no código:

- body: Organização vertical de todo o conteúdo da página (flex-direction: column)
e alinhamento centralizado (align-items: center).

- .cards-container e .galeria-grid: Distribuição dos cartões de conteúdo e das imagens em linha,
permitindo a quebra automática de itens quando a tela diminui (flex-wrap: wrap).

- .card-flex: Alinhamento lado a lado dos textos e das imagens nos
cartões informativos (flex-direction: row).

- .footer-nav: Alinhamento horizontal e centralizado dos links de navegação no
rodapé (justify-content: center e gap: 30px).

# Uso de IA:

O grupo não utilizou IA para a geração automática do código. O uso da tecnologia foi focado em pesquisas para entender como determinadas 
propriedades do Flexbox poderiam funcionar melhor (como no alinhamento e organização dos *cards*). 
Em resumo, a IA foi utilizada exclusivamente como ferramenta de pesquisa e aprendizado.
